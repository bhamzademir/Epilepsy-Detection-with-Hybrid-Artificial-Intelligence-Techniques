# Epileptic Seizure Detection using Hybrid AI Techniques

🚀 Detect epileptic seizure zones from EEG/iEEG signals using feature engineering, DWT, and machine learning.

## 🧠 Methods
- Preprocessing: DWT + statistical feature extraction
- Feature Selection: PCA, mRMR, ICA, RFE
- Models: SVM, Random Forest, LSTM, XGBoost
- Evaluation: Cross-validation, Accuracy, F1, ROC-AUC

## 📊 Results
Achieved 99.33% accuracy using XGBoost with PCA-based features.

## 📎 Tools
Python, Scikit-learn, Keras, GridSearchCV, Matplotlib
